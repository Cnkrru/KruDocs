## 一、资源管理器/文件浏览器设置

**注册表位置：**
```text
HKCU\Software\Microsoft\Windows\CurrentVersion\Explorer\Advanced
```

**常用键值含义：**

| 值名称 | 含义 | 当前系统值 |
|--------|------|-----------|
| `Hidden` | 是否显示隐藏文件（1=显示隐藏，2=不显示） | `1` |
| `ShowSuperHidden` | 是否显示系统受保护文件（1=显示） | `0` |
| `HideFileExt` | 是否隐藏已知文件扩展名（1=隐藏） | `0` |
| `DontPrettyPath` | 是否简化路径显示 | `0` |
| `SeparateProcess` | 是否在独立进程打开每个资源管理器窗口 | `0` |
| `TaskbarAnimations` | 任务栏动画 | `0` |
| `AutoCheckSelect` | 自动选择 | `0` |

**当前状态解读：** 显示隐藏文件、显示文件扩展名、不隐藏系统文件。

## 二、桌面/窗口外观设置

**注册表位置：**
```text
HKCU\Control Panel\Desktop
```

**常用键值含义：**

| 值名称 | 含义 | 当前系统值 |
|--------|------|-----------|
| `Wallpaper` | 桌面墙纸路径 | `D:\media_files\image\background.jpg` |
| `ScreenSaveActive` | 是否启用屏幕保护（1=启用） | `0` |
| `MenuShowDelay` | 菜单弹出延迟（毫秒） | `0` |
| `AutoEndTasks` | 关机时是否自动结束任务（1=自动） | `1` |

## 四、Internet 代理设置

**注册表位置：**
```text
HKCU\Software\Microsoft\Windows\CurrentVersion\Internet Settings
```

**常用键值含义：**

| 值名称 | 含义 | 当前系统值 |
|--------|------|-----------|
| `ProxyEnable` | 是否启用代理（1=启用） | `1` |
| `ProxyServer` | 代理服务器地址 | `127.0.0.1:19635` |
| `ProxyOverride` | 代理绕过列表 | `localhost;127.*;192.168.*;<local>` |

**说明：** 当前系统启用了本地代理（`127.0.0.1:19635`），可能是 VPN/加速器/抓包工具设置。

## 五、已安装程序列表

**注册表位置：**
```text
HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Uninstall\<程序>\DisplayName
HKLM\SOFTWARE\WOW6432Node\Microsoft\Windows\CurrentVersion\Uninstall\<程序>\DisplayName
HKCU\Software\Microsoft\Windows\CurrentVersion\Uninstall\<程序>\DisplayName
```

**当前系统：**
- 64 位已安装程序（HKLM）：**255 个**
- 32 位已安装程序（WOW64）：**334 个**

**列举部分（非驱动类）：** 7-Zip 26.02、MuMu模拟器、LinkAndroid、Claude Code Haha 0.5.3、微软OfficePLUS、NI Package Manager、Microsoft Visual Studio 2010 Tools、Microsoft Help Viewer 等。

**说明：** 该位置是"控制面板 → 程序和功能"的数据来源，包含大量 Windows 驱动包条目（FTDI、Arduino、STMicroelectronics、SEGGER、wch 串口驱动等嵌入式开发工具）。

## 六、其他常用功能注册位置汇总

| 功能 | 注册表位置 | 说明 |
|------|-----------|------|
| 系统图标设置 | `HKCU\Software\Microsoft\Windows\CurrentVersion\Explorer\CLSID` | 此电脑、网络等图标 |
| 命名空间 | `HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Explorer\MyComputer\Namespace` | 资源管理器侧栏项目 |
| 系统服务 | `HKLM\SYSTEM\CurrentControlSet\Services` | 所有系统服务定义 |
| 网络共享 | `HKLM\SYSTEM\CurrentControlSet\Services\LanmanServer\Shares` | 共享文件夹 |
| 输入法 | `HKCU\Software\Microsoft\InputMethod` | 输入法设置 |
| 键盘布局 | `HKCU\Keyboard Layout` | 键盘布局 |
| 电源策略 | `HKLM\SYSTEM\CurrentControlSet\Control\Power` | 电源计划 |
| 开机自启 | `HKCU\...\Run` 等 | 已另文记录 |
| 默认应用 | `HKCU\...\Explorer\FileExts` | 已另文记录 |
| 右键菜单 | `HKCR\...\shell` 等 | 已另文记录 |
| 环境变量 | `HKLM\SYSTEM\CurrentControlSet\Control\Session Manager\Environment` | 已另文记录 |
