## 一、各自启方式父级路径总览

| 自启方式 | 注册表/文件夹位置 | 说明 |
|----------|------------------|------|
| 当前用户 Run | `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` | 登录时启动当前用户程序 |
| 所有用户 Run | `HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Run` | 登录时启动所有用户程序 |
| 32 位 Run (HKLM) | `HKLM\SOFTWARE\WOW6432Node\Microsoft\Windows\CurrentVersion\Run` | 32 位程序（64 位系统） |
| 32 位 Run (HKCU) | `HKCU\SOFTWARE\WOW6432Node\Microsoft\Windows\CurrentVersion\Run` | 32 位程序（当前用户） |
| RunOnce（用户） | `HKCU\Software\Microsoft\Windows\CurrentVersion\RunOnce` | 登录时执行一次后删除 |
| RunOnce（系统） | `HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\RunOnce` | 启动时执行一次后删除 |
| 启动文件夹（用户） | `C:\Users\联想\AppData\Roaming\Microsoft\Windows\Start Menu\Programs\Startup` | 放置快捷方式 |
| 启动文件夹（系统） | `C:\ProgramData\Microsoft\Windows\Start Menu\Programs\Startup` | 所有用户快捷方式 |
| 计划任务 | `HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Schedule\TaskCache\Tree\<任务名>` | 可定时/登录触发 |
