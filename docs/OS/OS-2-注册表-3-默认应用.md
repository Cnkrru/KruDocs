## 一、注册表父级路径层级总览

Windows 文件类型关联的 KV 分散在多个注册表层级，父级路径与 KV 对应关系如下：

```text
HKCU\Software\Microsoft\Windows\CurrentVersion\Explorer\FileExts\<扩展名>
├── UserChoice\ProgId        # 用户指定的默认打开程序 ProgId
├── UserChoice\Hash          # 校验哈希（防篡改，直接改 ProgId 不更新 Hash 会被忽略）
├── OpenWithList\a,b,c...    # 「打开方式」历史记录（a=程序名, MRUList=最近使用顺序）
└── OpenWithProgids\<ProgId> # 推荐的打开程序列表（值为空字符串）

HKEY_CLASSES_ROOT\<扩展名>
└── (default) = <ProgId>     # 扩展名 → ProgId 的系统级映射

HKEY_CLASSES_ROOT\<ProgId>
├── shell\open\command\(default)   # 实际打开命令（可执行文件路径 + 参数）
└── Application\AppUserModelID     # UWP 应用身份标识

HKLM\SOFTWARE\RegisteredApplications   # 系统级注册的默认应用列表
```

**双击文件时的解析链路：**
```text
双击文件 → FileExts\<扩展名>\UserChoice\ProgId
        → HKCR\<ProgId>\shell\open\command → 执行程序
```
