## 一、父级路径层级总览
```text
HKCU\Environment                                   # 用户级环境变量（TEMP/TMP 等）
HKLM\SYSTEM\CurrentControlSet\Control\Session Manager\Environment   # 系统级环境变量（TEMP/TMP、Path 等）
```

| 层级 | 注册表位置 | 说明 |
|------|-----------|------|
| 用户级 | `HKCU\Environment` | 用户临时目录，同时存 JAVA_HOME、MAVEN_HOME、NVM_HOME 等 |
| 系统级 | `HKLM\SYSTEM\CurrentControlSet\Control\Session Manager\Environment` | 系统临时目录，同时存系统级 Path 等 |

---

## 二、临时目录 KV 大表

| 类型 | 名称（k） | 值数据（v） | 注册表位置（父级路径） |
|------|-----------|-------------|------------------------|
| 用户级环境变量 | `TEMP` | `C:\Users\联想\AppData\Local\Temp` | `HKCU\Environment` |
| 用户级环境变量 | `TMP` | `C:\Users\联想\AppData\Local\Temp` | `HKCU\Environment` |
| 系统级环境变量 | `TEMP` | `C:\Windows\TEMP` | `HKLM\SYSTEM\CurrentControlSet\Control\Session Manager\Environment` |
| 系统级环境变量 | `TMP` | `C:\Windows\TEMP` | `HKLM\SYSTEM\CurrentControlSet\Control\Session Manager\Environment` |

> `TEMP` 与 `TMP` 为同一路径的别名，进程实际使用的临时目录遵循「当前用户 TEMP 优先于系统 TEMP」的合并规则。

## 三、非注册表的缓存路径

| 目录 | 位置 |
|------|------|
| 用户临时目录 | `C:\Users\联想\AppData\Local\Temp` |
| Chrome 缓存 | `C:\Users\联想\AppData\Local\Google\Chrome\User Data` |
| Edge 缓存 | `C:\Users\联想\AppData\Local\Microsoft\Edge\User Data\Default\Cache` |
| 缩略图缓存 | `C:\Users\联想\AppData\Local\Microsoft\Windows\Explorer` |
| 崩溃转储 | `C:\Users\联想\AppData\Local\CrashDumps` |
| 系统临时目录 | `C:\Windows\Temp` |
| Windows 更新缓存 | `C:\Windows\SoftwareDistribution\Download` |
| Prefetch | `C:\Windows\Prefetch` |
