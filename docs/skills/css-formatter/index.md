# css-formatter

CSS 格式化规范 SKILL，提供统一的 CSS 书写规范和检查标准。

## 功能特性

- 统一格式: 键值对一行书写规范
- Flex 优先: 禁止 Grid，统一使用 Flex 布局
- 文件分区: 三区域结构（基础样式 / 颜色变量引用 / 媒体查询）
- 断点规范: 统一响应式断点（576 / 768 / 1024 / 1200 / 1400）
- 颜色管理: 全局 color.css 统一管理，禁止私自定义

## 规范分类

| 分类 | 说明 |
|------|------|
| 格式规范 | 键值对书写规则 |
| 布局规范 | Flex 优先，禁止 Grid |
| 文件结构 | 三区域分区规则 |
| 媒体查询 | 响应式断点标准 |
| 颜色管理 | 全局变量引用规则 |
