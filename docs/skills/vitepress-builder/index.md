# vitepress-builder

一键搭建 VitePress 文档站点的 SKILL，只需提供文件夹名称，自动创建完整项目结构。

## 功能特性

- 极简操作: 只需提供文件夹名称
- 一键生成: 自动创建完整项目结构
- 中文界面: 所有 UI 文本中文化
- 本地搜索: 默认启用，开箱即用
- 自定义主题: 支持个性化定制
- 部署就绪: 包含 Vercel/Netlify 部署配置

## 技术栈

- VitePress: ^1.6.4
- Vue: 3.x
- Node.js: >= 18.x
