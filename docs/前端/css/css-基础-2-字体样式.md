## 1. 文字效果
### 1.1 尺寸
| 属性 | 说明 |
| --- | --- |
| **font-size** | num+px |
| **说明** | px指的是像素大小 |
| **默认值** | 谷歌浏览器默认字体大小是16px |
### 1.2 粗细
| 属性 | 说明 |
| --- | --- |
| **font-weight** | num |
### 1.3 行高
| 属性 | 说明 |
| --- | --- |
| **line-height** | num+px |
| **说明** | 如果只写num，则为当前标签的字符大小的num倍；行高=上间距+下间距+字体大小 |
### 1.4 颜色
| 颜色表示法 | 说明 |
| --- | --- |
| **color** |  |
| **rgb三原色写法** |  |
| **rgba透明色表示法** | a表示透明度，属于（0，1）小 |
| **十六进制表示** | RRGGBB（如果重复，则写成RGB） |
> 基本上一个字体大小+行高就行了

## 2. 排版布局
### 2.1 横向位置
| 属性 | 说明 |
| --- | --- |
| **text-align** | style |
| **left** | 默认左 |
| **right** |  |
| **center** | 居中的是字体 |
- **图片居中**：需要给img标签加一个父级：div
### 2.2 垂直居中（行高特殊作用）
- **方法**：
  - 造一个盒子
  - 把文字行高和盒子高度设置一样就行
- **说明**：仅限单行文字垂直居中
### 2.3 单词换行
- word-warp: break-word
### 2.4 长句子拆分换行
- word-break: keep-all/break-all
> 没那么多讲究，居中一般用flex，需要换行的基本遇不到

| 属性 | 说明 |
