# CSS

---
## 1. Flex（弹性布局）

### 1.1 容器属性

| 属性 | 说明 | 可选值 |
| --- | --- | --- |
| **display: flex** | 启用弹性布局 |  |
| **flex-direction** | 设置主轴方向 | row（默认）、column |
| **justify-content** | 设置主轴对齐方式 | center、space-between、space-around |
| **align-items** | 设置交叉轴对齐方式 | center、stretch（默认） |
| **flex-wrap** | 设置是否换行 | nowrap（默认）、wrap |
| **align-content** | 设置多行对齐方式 | center、space-between、space-around、stretch（默认） |

---
### 1.2 项目属性

| 属性 | 说明 |
| --- | --- |
| **flex** | 设置项目伸缩比例（可填写px/1、2之类的比例） |
| **flex-grow** | 设置项目放大比例 |
| **flex-shrink** | 设置项目缩小比例 |
| **flex-basis** | 设置项目初始大小 |
| **order** | 设置项目排列顺序 |
| **align-self** | 设置单个项目对齐方式 |
