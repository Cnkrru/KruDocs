## 1. 显示模式

### 1.1 常用的显示模式
| 模式 | 特点 | 默认元素 |
| --- | --- | --- |
| block（块级元素） | 独占一行，可设置宽高，可设置边距 | div、p、h1-h6、ul、ol、li等 |
| inline（行内元素） | 不独占一行，不可设置宽高，水平边距有效 | span、a、strong、em、i、b等 |
| flex（弹性布局） | 弹性容器，灵活布局 | 导航栏、卡片网格、居中对齐 |
---
### 1.2 显示模式的转换
| 目标类型 | CSS写法 |
| --- | --- |
| 块级元素 | `display: block;` |
| 行内元素 | `display: inline;` |
| 弹性容器 | `display: flex;` |
---
> inline不怎么用，一般布局用flex，然后做一些功能时用block和none(不显示)
