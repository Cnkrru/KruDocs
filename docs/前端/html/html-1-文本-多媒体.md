## HTML基础标签与操作
---
## 1. 文本相关标签

| 标签 | 说明 |
|------|------|
| **h** | 标题（独占一行，加粗） |
| **p** | 段落（独占一行） |

> 实际写的时候没啥用，很少写
---
## 2. 多媒体相关标签
### 图像标签
- **img**（单标签）

| 属性 | 说明 |
|------|------|
| **src** | 图像路径 |
| **alt** | 失败替换文本 |
| **title** | 图像名称 |
| **width** | 图像宽度 |
| **height** | 图像高度 |

> 一般只写个src和alt，其他懒得写，宽高一般CSS来弄
### 音频标签
- **audio**

| 属性 | 说明 |
|------|------|
| **src** | 路径 |
| **controls** | 控制面板（不需要=填写属性值） |
| **loop** | 循环播放 |
| **autoplay** | 自动播放 |

> 很少写，而且有成熟更好用的Aplayer，自定义时写JS和CSS来控制
### 视频标签
- **video**

| 属性 | 说明 |
|------|------|
| **src** | 路径 |
| **controls** | 控制面板 |
| **loop** | 循环 |
| **muted** | 静音播放 |
| **autoplay** | 自动播放（自动需要配合静音播放一起使用） |

> 基本没写过
