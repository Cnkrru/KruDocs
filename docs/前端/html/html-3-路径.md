## 链接与路径
---
### 超链接标签
- **a**

| 属性 | 说明 |
|------|------|
| **href** | URL/本地相对路径（初期不知道跳转到哪里，href=#，空连接） |
| **target** | _打开方式 |
---
### 路径
- **相对路径**
  - 从当前位置出发，找本地
  - 表示方法：

| 写法 | 说明 |
|------|------|
| 文件夹名/ | 进入该文件夹 |
| ./ | 进入当前文件夹 |
| ../ | 进入上一级文件夹 |
| 每多一个点，多进入一级 | 多进入一级 |
- **绝对路径**
  - 从盘符位置出发，找网页
  - 本地文件不用
- **路径分隔符**
  - 所有系统默认：/
  - Windows默认：\，但全使用/
> 路径这块比较重要，很多问题都和路径有关
> 实际开发中很少用绝对路径，一般是相对路径链接文件，绝对路径一般是让用户自己选择一个路径
> 如果使用vue这种框架，还会遇到@作为根路径，@在配置里一般和项目的一个文件绑定，编译时路径会进行替换，替换为输出目录下正确的链接路径
