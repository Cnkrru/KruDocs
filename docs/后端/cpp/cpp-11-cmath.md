## 2. 常用函数

### 2.1 取整

| 函数 | 说明 |
| --- | --- |
| `round(<num>)` | 四舍五入 |
| `floor(<num>)` | 向下取整 |
| `ceil(<num>)` | 向上取整 |
| `trunc(<num>)` | 截断取整 |

### 2.2 方根运算

| 函数 | 说明 |
| --- | --- |
| `pow(<num>, <num>)` | 幂运算 |
| `sqrt(<num>)` | 平方根 |
| `cbrt(<num>)` | 立方根 |
| `hypot(<num>, <num>)` | 斜边 |

### 2.3 绝对值

| 函数 | 说明 |
| --- | --- |
| `abs(<num>)` | 绝对值 |
| `fabs(<num>)` | 浮点数绝对值 |

### 2.4 三角函数

| 函数 | 说明 |
| --- | --- |
| `sin(<num>)` | 正弦 |
| `cos(<num>)` | 余弦 |
| `tan(<num>)` | 正切 |
| `asin(<num>)` | 反正弦 |
| `acos(<num>)` | 反余弦 |
| `atan(<num>)` | 反正切 |

### 2.5 指对运算

| 函数 | 说明 |
| --- | --- |
| `exp(<num>)` | 指数运算 |
| `log(<num>)` | 对数 |
| `log10(<num>)` | 常用对数 |
| `log2(<num>)` | 以2为底的对数 |

### 2.6 最值运算

| 函数 | 说明 |
| --- | --- |
| `min(<num>, <num>)` | 最小值 |
| `max(<num>, <num>)` | 最大值 |
