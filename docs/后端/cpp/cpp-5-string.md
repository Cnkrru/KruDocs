# Cpp-string

## 1. 模块介绍

- **string**是标准库的字符串类型，提供了python字符串类型自带的那些一样的功能
- OK

---

## 2. 常用操作

| 分类 | 操作 | 说明 |
| --- | --- | --- |
| **创建** | `std::string var_s;` | 创建数据类型string |
| **拼接** | `var_s1 + '' + var_s2` | 支持+拼接字符串 |
| **追加** | `var_s.append(<内容>)` | 支持append追加 |
| **长度** | `var_s.size()` | 返回字节数 |
| | `var_s.empty()` | 返回布尔值 |
| **截取** | `var_s.substr(<参数>)` | 支持参数切割字符串 |
| **查找** | `var_s.find(<字符串>)` | 查找的是第一次出现的位置 |
| **替换** | `var_s.replace(<参数>, <字符串>)` | 支持replace替换 |
| **插入** | `var_s.insert(<参数>, <字符串>)` | 支持insert插入字符串 |
| **删除** | `var_s.erase(<参数>)` | 支持erase删除字符串 |

### 参数说明

| 参数 | 范围 |
| --- | --- |
| n | 下标索引 |
| (m, n) | m到n |
