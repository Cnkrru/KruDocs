# Cpp-fmt

## 1. 模块介绍

- **fmt**是第三方库，只能输出
- 导入 `#include <fmt/<子文件>>` → 如果是用包管理器vcpkg，需要在配置json写出其位置
- OK

---

## 2. core.h

| 方法 | 说明 |
| --- | --- |
| `print()` | 格式化输出，{},{},{} 支持参数传递 |

---

## 3. color.h

| 方法 | 说明 |
| --- | --- |
| `fg()` | 前景色，`print(fmt::fg(fmt::color::<颜色>), <字符串>)` |
| `bg()` | 背景色，`print(fmt::bg(fmt::color::<颜色>), <字符串>)` |
