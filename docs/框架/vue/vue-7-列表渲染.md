## 列表渲染

### 个人理解

> 列表渲染 `v-for` 是 Vue 设计专门用于列表渲染的指令，把原本的 JS 逻辑简化。

| 项目 | 说明 |
|------|------|
| 原理 | 和后端的 for 循环一样，遍历数组，根据数组的每个元素渲染对应的 HTML |
| 语法 | `v-for="item in array"`，`item` 是数组的每个元素，`array` 是数组 |

### 内置方法

> Vue 给对象类型专门配置一套类似数组操作的方法。

| 方法 | 说明 |
|------|------|
| `push()` | 向数组末尾添加元素 |
| `pop()` | 删除数组末尾的元素 |
| `shift()` | 删除数组开头的元素 |
| `unshift()` | 向数组开头添加元素 |
| `splice()` | 删除/替换/添加元素 |
| `sort()` | 排序 |
| `reverse()` | 反转 |
