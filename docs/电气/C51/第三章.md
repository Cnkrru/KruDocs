## 指令

1. 按字节分类：
   - 单字节
   - 双字节
   - 三字节
2. 按机械周期分类：
   - 1个机械周期
   - 2个机械周期
   - 4个机械周期
3. 操作码与操作数
   - 操作码：命令
   - 操作数：可以是直接的数字，也可以是地址

## 寻址方式（7种）

| 寻址方式 | 说明 | 寻址范围 |
|----------|------|----------|
| 寄存器寻址 | 操作指定寄存器存储的数值（寄存器的数值） | 通用寄存器（R0-R7）、特殊寄存器 |
| 直接寻址 | 操作数值对应的地址的数值（地址的数值） | 片内RAM地址、特殊寄存器 |
| 寄存器间接寻址 | 操作指定寄存器的数值所对应的地址的数值（寄存器内的地址的数值） | 片内RAM地址、片外RAM地址、堆栈操作 |
| 立即数寻址 | 直接传递数 | - |
| 基址寄存器+变址寄存器间接寻址 | 基址寄存器（DPTR,PC）+ 变址寄存器（A），先把两个寄存器的地址相加，再按地址寻址 | 指令（3条）：MOVC A,@A+DPTR、MOVC A,@A+PC、JMP @A+DPTR |
| 相对地址寻址 | 操作相对地址的数值（-128~+127） | - |
| 位寻址 | 操作指定地址的数值 | - |

> 总结下来只有两类：地址寻址，寄存器寻址

## 指令集备注

| 指令目标 | 说明 |
|----------|------|
| A | 累加器 |
| Rn | 通用寄存器 |
| direct | 直接地址 |
| @Ri | 间接寻址寄存器 |
| DPTR/PC | 指针寄存器 |

### MOVC

- DPTR指针模板
  ```asm
  MOV A,#01H              ; 01H为下标索引
  MOV DPTR,#ARRAY         ; 将数组入口地址传给数据指针
  MOVC @A,A+DPTR          ; 根据索引拿到地址
  ```
- PC指针设计思路
  > PC指针查表依赖程序位置，需要从当前位置计算出与数组地址之间的距离，补全距离来查表
  > 一般情况下，查表用DPTR指针

## 指令集

### 1. 赋值指令

| 指令 | 说明 |
|------|------|
| MOV <地址/寄存器>,<地址/寄存器> | 用于访问片内RAM |
| MOVX <地址/寄存器>,<地址/寄存器> | 用于访问片外RAM，要配合RD,WR引脚使用 |
| MOVC <地址/寄存器>,<地址/寄存器> | 用于访问ROM中连续地址预设的数组（查表），唯一可访问ROM的数据指令，只读类型，要伴随PSEN引脚使用 |

> MOVC一般采用相对地址寻址，只有两条指令：
> - MOVC A,@A+PC -> 在A+PC+1处运行
> - MOVC A,@A+DPTR -> 在A+DPTR处运行
