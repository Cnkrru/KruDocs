## 串口

| 特性 | 说明 |
|------|------|
| 工作方式 | 全双工，异步收发 |
| 收/发缓冲器 | SUBF（共用一个寄存器地址99H） |

---

## 工作模式

### SCON 寄存器

| 位 | 标识 | 说明 |
|----|------|------|
| SCON.7 | SM0 | 与SM1、SM2共同控制串口工作模式 |
| SCON.6 | SM1 | 与SM0、SM2共同控制串口工作模式 |
| SCON.5 | SM2 | 用于多机通信，控制是否收发信息 |
| SCON.4 | REN | 0:禁止接收；1:允许接收 |
| SCON.3 | TB8 | 第9位数据位 |
| SCON.2 | RB8 | 第9位数据位 |
| SCON.1 | TI | 发送完成标志，接收完数据由硬件置1 |
| SCON.0 | RI | 接收完成标志，接收完数据由硬件置1 |

### SM0, SM1, SM2 工作模式

| SM0 | SM1 | 模式 | 说明 |
|-----|-----|------|------|
| 0 | 0 | 方式0 | 同步移位寄存器（用于拓展IO口） |
| 0 | 1 | 方式1 | 8位异步收发（波特率可变，由定时器控制） |
| 1 | 0 | 方式2 | 9位异步收发（波特率为 f/64 或 f/32） |
| 1 | 1 | 方式3 | 9位异步收发（波特率可变，由定时器控制） |

> SM2=1，只有第9位=1时，接收数据；SM2=0，无脑接收数据

### RB8/TB8 数据位

| 值 | 说明 |
|----|------|
| 0 | 串口8位数据位 |
| 1 | 串口9位数据位 |

### SMOD

| 位 | 说明 |
|----|------|
| PCON.7 -> SMOD | 波特率选择位；SMOD=1相比SMOD=0，波特率翻倍 |

### 工作模式详解

| 方式 | 说明 | 波特率 |
|------|------|--------|
| 方式0 | 8位同步，用于外拓IO，无起始位和终止位 | f/12 |
| 方式1 | 10位双机通信，1位起始位和1位终止位 | 2^SMOD/32 \* 定时器T1溢出率 |
| 方式2 | 11位异步通信，1位起始位+8位数据位+1位可控第9位+1位终止位 | 2^SMOD/64 \* f |
| 方式3 | 9位异步通信，其余与方式2一样 | 2^SMOD/32 \* 定时器T1溢出率 |

> 溢出率：(f/12) / (256-x)

### 波特率制定方法

- 收发双方波特率必须一致

## 程序示例

### 甲机发送程序（外部中断式）

```asm
ORG 0000H
SJMP MAIN
ORG 0003H
SJMP INT0
ORG 000BH
SJMP TIM0

MAIN:
    MOV TMOD,#20H
    MOV TL1,#0F4H
    MOV TH1,#0F4H
    MOV PCON,#00H
    MOV SCON,#40H

    SETB EA
    SETB ES
    SETB TR1

    MOV SBUF,20H
    SJMP $

COMINT:
    CLR TI
    CLR EA
    CLR ES
    RETI 
    END
```

### 甲机发送程序（轮询）

```asm
ORG 0000H
MAIN:
    MOV TMOD,#20H
    MOV TL1,#0F4H
    MOV TH1,#0F4H
    MOV PCON,#00H
    MOV SCON,#40H

    SETB TR1
    MOV SBUF,20H
    JNB TI,$
    CLR TI
    END
```

### 乙机接收程序

```asm
ORG  0000H
SJMP MAIN
ORG  0023H
SJMP COMINT
ORG  0030H

MAIN: 
    MOV TMOD,#20H
    MOV TL1,#0F4H
    MOV TH1,#0F4H
    MOV PCON,#00H
    MOV SCON,#50H
    SETB ES 
    SETB EA
    SETB TR1 
    SJMP  $

COMINT:
    CLR RI
    MOV 20H,SBUF
    CLR EA
    CLR ES
    RETI 
    END
```

   - 波特率 = 帧数 \* 位
   - 1200

   - f/12

   - 两种通信形式：串行，并行
   - 串行通信时：
     - 发送：并行数据转串行数据
     - 接收：串行数据转并行数据

   - 双方应该波特率相等
