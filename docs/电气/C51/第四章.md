## 中断

### TCON 寄存器

| 位 | 标识 | 说明 |
|----|------|------|
| TF0 | TCON.5 -> 8DH | TIM0溢出标志位 |
| TF1 | TCON.7 -> 8FH | TIM1溢出标志位 |
| IE0 | TCON.1 -> 89H | 外部中断0请求标志位 |
| IE1 | TCON.3 -> 8BH | 外部中断1请求标志位 |
| IT0 | TCON.0 -> 88H | 外部中断0触发方式：电平触发 |
| IT1 | TCON.2 -> 8AH | 外部中断1触发方式：跳沿触发 |

### SCON 寄存器

| 位 | 标识 | 说明 |
|----|------|------|
| RI | SCON.0 -> 98H | 串口发送完成标志位 |
| TI | SCON.1 -> 99H | 串口接收完成标志位 |

## 中断允许寄存器（IE）

> 高电平有效

| 位 | 标识 | 说明 |
|----|------|------|
| EA | - | 中断总开关 |
| ET0 | - | 定时器0溢出中断允许位 |
| ET1 | - | 定时器1溢出中断允许位 |
| ET2 | - | 定时器2溢出中断允许位 |
| EX0 | - | 外部中断0允许位 |
| EX1 | - | 外部中断1允许位 |
| ES | - | 串口中断允许位 |

操作：
> CLR <E寄存器>
> SETB <E寄存器>

## 中断请求的撤销

| 中断类型 | 撤销方式 |
|----------|----------|
| TIM中断 | TIM0/1中断自动撤销；TIM2中断需要手动撤销 -> CLR TF2+CLR EXF2 |
| INFO中断 | 两种触发方式下都自动撤销 |
| USART中断 | CLR TI, RI |

## PPT

1. 中断地址要记住
   - 程序存储ROM，不能占用中断位置
2. I<>, T<>, E<>, P<>
   - I<>：中断控制寄存器 -> INFO
   - T<>：中断控制寄存器 -> TIM
   - E<>：中断允许寄存器
   - P<>：中断优先级寄存器
3. 中断级别顺序（同级别时）
   - INF0 > TIM0 > INF1 > TIM1 > USAT > TIM23
4. 周期
   - 外部中断最短响应时间：3个机械周期，最长8个机械周期
   - 最短：中断查询标志位占，1个机械周期，该机械周期处于指令最后一个机械周期，接着调用LCALL，占两个机械周期
   - 最长：中断查询标志位占，1个机械周期，访问RET，1个机械周期，计算（乘除法）4个机械周期，调用LCALL，2个机械周期

### 中断程序设计

```asm
ORG 0000H
    LCALL MAIN
ORG 0003H
    LCALL INT
ORG 000BH
    LCALL TIM0

INT:
    中断事件    
```

2. 优先级设置，一般用位指令 -> SETB和CLR
