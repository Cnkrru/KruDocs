# 变压器
## 第一章：
1. 单相
    - S_N =U_N*I_N
2. 三相
    - S_N = 根号三U_N*I_n
        - 都是额定值，也都是线参数，相参数需要二次求
## 第二章：
1. 励磁参数
    - r：P_0*/(I_0*)²
    - x：用另外两个求
    - z：1/I_0*
2. 短路参数
    - r：P_kn*
    - x：用另外两个求
    - z：U_kn*
3. 电压变化率
    - 电压变化率：β(r_k*cos+x_k*sin)
4. 效率
    - 效率：(p0+β²p_kn)/(p0+β²*p_kn+β*S_N*cos)
## 第三章:
1. 并联运行
    - S_A:S_B = S_AN/Z_A :S_BN/Z_B = β_1:β_2
2. 不对称分量 -> 对称分量
    - +/-/0
        - +：1/3(U_A+α*U_B+α²U_C)
        - -：1/3(U_A+α²*U_B+α*U_C)
        - 0：1/3(U_A+U_B+U_C)
            - α:120°
## 第四章：
1. 计算短路电流
    - I_k = U_1N/Z_k
        - I_k = I_K* * I_N1
            - I_k* = 1/Z_k*

# 绕组
## 第六章
1. 求参数
    - p
    - α = 360*p/Z
    - q = Z/2pm
    - t = Z/2p
    - y = (1-1/v)*t
    - N = 绕组层数*pqN_c/a
> 如果短距系数求不出来，说明不用求，不用管
## 第七章
1. n=60f/p
2. 系数
    - 短距系数：sin(90°*(y/t))
    - 分布系数：sin(qα/2)/qsin(α/2)
3. 电动势
    - 导体电动势：2.22f*磁通
    - 线匝电动势：4.44f*磁通*短距系数
    - 线圈电动势：4.44f*N*磁通*短距系数
    - 线组电动势：4.444f*N*磁通*短距系数*分布系数
        - 如果是求谐波，则只有两个系数不同
## 第八章
0. 3n次谐波磁动势不存在
1. n=60f/vp
2. 磁动势
    - 基波磁动势：1.35*(N*短距系数*分布系数/P)*运行相电流
    - 谐波磁动势：1.35*(N*短距系数*分布系数/vp)*运行相电流
    - 旋转磁动势：就是上面俩公式，1.35是越等的参数

# 异步电机
## 第九章
1. 转差率
    - n-n_N/n
2. 功率
    - 输出：P_N
    - 输入：gen_3*U_N*I_N*cos
## 第十章
1. 求负载电流
    - I = U/Z
    - 如果串新电阻，只算r的部分
## 第十一章
1. 电磁功率的公式
    - 输入P1
        - 定子铜耗铁耗Pcu，Pfe
            - 电磁功率 = P1-Pcu-Pfe
                - 电磁功率 = 转子铜损+机械功率
                    - 机械功率 = 额定功率+机械磨损
2. 转矩：
    - 电磁转矩：Pem         ，额定角速度(转速求)
    - 机械转矩：Pmsc        ，实际角速度
    - 输出转矩：P2          ，实际角速度
    - 空载转矩：Pcu+Pfe     ，实际角速度
