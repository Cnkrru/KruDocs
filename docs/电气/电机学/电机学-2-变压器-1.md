## 变压器
### 原理
1. 电磁感应原理，不改变频率，只改变电压，传递能量。
2. 变压过程  
    - 发电端低压，经过升压变压器到高压输电线，高压输电，电流小，损耗小，到用户端经过多级降压变压器，传给用户。
3. 具体工作原理：  
    - 一次侧接入交流电，在铁心产生磁通，磁通在一二次侧产生相同频率的感应电动势，此时在二次侧接入负载，则可以把能量传递过去
### 结构
主要：铁心，绕组
次要：油箱，绝缘套管，分压开关
1. 铁心用硅钢片的原因：减少磁滞和涡流损耗
2. 片间涂厚漆膜：防止片间短路
### 额定值
1. S：一次侧额定容量=二次侧额定容量
2. U：一次侧额度电压指规定的电压，二次侧的额定电压指一次侧达到额定电压时，二次侧空载运行时的电压
    - 三相：额定电压指的是线电压
3. I：与电压同理
    - 三相：线电流
4. f：50Hz
### 负载
1. 负载指的是二次侧的电流，而不是阻抗
### 问题
1. 铁心的作用：构成闭合磁路，一次侧加电压，产生磁通，二次侧产生感应电动势，传递能量
2. 油式变压器组件：铁心，绕组，油箱，分接开关，绝缘套管
3. 油的作用：绝缘，防止击穿，冷却散热
4. 变压器的额定值：容量，电压，电流，频率
5. 二次侧额定电压：一次侧达到额定电压值时，二次侧的电压
6. 变压器运行原理：电磁感应定律
7. 能否用于直流电：不能，直流电无法产生交变磁通，不能在副边产生感应电动势
### 计算
1. 单相，知道Sn，Un1，Un2，求In
2. 三相，知道Sn，Un1，Un2，求两侧额定电压，电流
> 注意，计算变比时，选择相/线，分子分母要一致

## 空载运行
### 现象
1. 一次侧接入电压，二次侧空载，一次侧电流空载电流i0
2. 空载电流经过一次绕组产生磁动势F=i0×N，并建立空载磁通（主磁通）与漏磁通
3. 主磁通磁通产生两侧感应电动势E1,E2
    - 两侧感应电动势≈一次侧加入电压，等于一次侧加入电压+IR
    - 空载电流是额定电流的2%-10%
    - 主磁通与两侧都交链，所以与i0是非线性关系。
    - 漏磁通只与一次侧交链，与i0为线性关系
        - 漏磁通占空载磁通不到1%，主磁通占大部分
8. 损耗主要分为铁耗和铜耗，铁耗占80%，铜耗是发热，占的少
9. 空载时，二次侧不消耗能量，能量以损耗形式流失
- 主磁通：传递能量
- 漏磁通：形成降电势
    - 漏磁通也产生感应电动势
        - 4.44fN_1*漏磁通
            - = I_0*x(漏电感)
                - I_0指的是空载电流
                - x = w*L = w*N_1²*常数
### 空载运行各电磁量的关系
1. E（t）=wN磁通sin（wt-π/2）
2. E（max）=wN磁通（max）
3. E（有效）=E（max）/√2
4. E（有效）=4.44Nf磁通（max）
    - 4.44=√2π
### 电压平衡方程式
1. U_1 = -E_1 - E_漏 + IR
    - E_漏 = Ix
        - U_1 = -E_1 + I(R+xj)
            - R+xj为漏阻抗
2. 五个基本方程
    1. U = -E+IR
    2. E_1 = 4.44fN*磁通
    3. I_0 = -E_1/Zm
    4. E_2 = 4.44fN*磁通
    5. U_20 = E_2

## 特性
### 电压调整率
- 一次侧加额定电压，fN不变
    - 二次侧端电压U2随负载电流I2（负载系数β）变化的情况
- 电压变化率
    - 电压变化率 = U2额定值 - U2实际值 / U2额定值
    - 电压变化 = U2额定值-U2实际值 = β(Rx*cos(α)+Zx*sin(α))
        - β = I2实际值 / I2额定值
- β越小越好，漏阻抗越小越好，电压变化率就越小
### 效率特性
- 效率 = 输出有功功率P2 / 输入有功功率 P1
    - P1 = P2+P(fe)+P(cu)
        - P(fe):固定值，与β无关
        - P(cu):= β²*P(kn)
        - P2:β*Sn*cos(角度2)
- 效率最大值：铁耗 = 铜耗
    - β一般在0.5-0.6
    - 计算时，P(fe) < P(kn)
