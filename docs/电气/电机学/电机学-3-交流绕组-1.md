## 交流绕组
### 基本概念
1. 空间电角度
    - α_电 = p*α_机
        - α_机：机械角度
        - p：电极对数
2. 每极每相槽数
    - q = Z/2pm
        - Z：总槽数
        - p：极数
        - m：相数
3. 槽间角
    - α_1 = p*360/Z
4. 相带
    - q*α_1
5. 极距
    - t = Z/2p
6. 节距
    - 一个边两有效边之间的距离

## 感应电动势
### 基波与谐波电动势
1. 一根导体
    1. 导体基波电动势
        - E = 2.22f磁通
    2. 导体多次谐波电动势
        - E = 2.22vf磁通
2. 整距线匝(相当于两根导体)
    1. 基波
        - E = 4.44f磁通
            - N匝
                - E = 4.44Nf磁通
    2. 多次谐波
        - E = 4.44vf磁通
3. 短距线匝(一侧导体长度不足)
    1. 基波
        - E = 4.44fk_y磁通
            - k_y：短距系数
            - k_y = cos((y/t)*90°)
    2. 多次谐波
        - E*v
4. 分布系数(多个线匝交错)
    1. 基波
        - E= 4.44fk_w磁通
            - k_w：分布系数
            - k_w：sin((q*α_1)/2)/q*sin((α_1)/2)
    2. 谐波
        - E*v
> 采用短距和分布主要是为了减少谐波影响
### 线电动势
1. 星形
    - 线 = 根号3*相
2. 角形
    - 线 = 相
    - 会引起环流
> 一般采用星形，而不是角形，因为环流会增加损耗，升温导致效率降低

## 磁动势
### 一相绕组磁动势
1. 转速
    - n = 60f/p
2. 磁动势
    - F = Fcos(wt)cos(α)
### 三相绕组磁动势
1. 基波
    1. F_A = Fcos(wt)cos(α)
    2. F_B = Fcos(wt-120)cos(α-120)
    3. F_C = Fcos(wt-240)cos(α-240)
    - F = F_A + F_B + F_C
        - F = 1.5*Fcos(wt-α)
2. 谐波
    1. 三相绕组不含3次谐波
    2. n次谐波
        - 5次(6k-1)
        - 7次(6k+1)
