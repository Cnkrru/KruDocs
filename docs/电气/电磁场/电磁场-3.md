## 恒定磁场
### 安培力定律
1. 恒定磁场
    - 恒定电流产生恒定磁场
    - 恒定磁场对运动电荷有力的作用

|静电场|恒定磁场|
|---|---|
|静电荷|恒定电场|
|对静止电荷有力|对运动电荷有力|

2. 安培力定律
    - $$F = B\cdot I\cdot L$$（电流元 l 与 B 垂直）
    - 毕奥-萨伐尔定律：$$dB = \frac{\mu}{4\pi}\cdot\frac{Idl\times\hat{r}}{r^2}$$
        - 线电流：$$B = \frac{\mu}{4\pi}\int\frac{Idl\times\hat{r}}{r^2}$$
        - 面电流：$$B = \frac{\mu}{4\pi}\int\frac{K\times\hat{r}}{r^2}\,dS$$
        - 体电流：$$B = \frac{\mu}{4\pi}\int\frac{J\times\hat{r}}{r^2}\,dV$$
---
### 磁通连续性原理
1. 磁通
    - $$\Phi = B\cdot S$$
    - 恒定磁场是无散场
2. 安培环路定理
    - $$\oint B\cdot dl = \mu_0 I$$
3. 介质磁化
    - 介质内有磁偶极子
        - 磁偶极子原本的方向是杂乱无章，经过磁化，方向趋于一致，产生磁化电流
            - 磁化电流的电流密度为 $J_m$
        - 磁化强度 $$M = \frac{P_m}{V}$$
            - 关联式：$$\oint M\cdot dl = J_m\cdot S$$（即磁化电流 $$I_m = \oint M\cdot dl$$）
        - 磁化电流与原本的电流叠加，影响磁感应强度
            - $$\oint B\cdot dl = \mu_0(I + I_1)$$
    - 结果
        - $$\oint B\cdot dl = \mu_0(I + I_1)$$
        - $$I_1 = \oint M\cdot dl$$
            - $$\oint B\cdot dl = \mu_0(I + \oint M\cdot dl)$$
                - $$B = \mu_0(H + M)$$... 见下
    - 磁场强度 H
        - $$H = \frac{B}{\mu_0} - M$$
    - 一般情况的安培环路定律
        - $$\oint H\cdot dl = I$$
4. 磁导率 μ
    - $$B = \mu_0(H + M)$$，其中 $$M = \chi_m H$$
    - $$\mu = \mu_0(1 + \chi_m) = \mu_0\mu_r$$
        - $\mu_r = 1 + \chi_m$：相对磁导率，$\chi_m$ 为磁化率
5. 基本方程
    - $$\oint B\cdot dS = 0$$（磁通连续性）
        - 微分形式：$$\nabla\cdot B = 0$$
    - $$\oint H\cdot dl = I$$（安培环路）
        - 微分形式：$$\nabla\times H = J$$
6. 边界面衔接条件
    - $$H_{2t} - H_{1t} = k$$
        - k：电流线密度
    - $$B_{1n} - B_{2n} = 0$$
---
### 磁矢位
1. 磁矢位 A
    - $$\nabla\cdot B = 0 \rightarrow B = \nabla\times A$$（磁矢位自动满足磁通连续性）
    - $$\nabla\times H = J$$，$$B = \mu H$$
        - $$\nabla\times B = \mu J \rightarrow \nabla\times(\nabla\times A) = \nabla^2 A = -\mu J$$
    - A 满足的泊松方程：$$\nabla^2 A = -\mu J$$
    - A 的计算公式
        - 线电流：$$A = \frac{\mu}{4\pi}\int\frac{Idl}{r}$$
        - 面电流：$$A = \frac{\mu}{4\pi}\int\frac{K}{r}\,dS$$
        - 体电流：$$A = \frac{\mu}{4\pi}\int\frac{J}{r}\,dV$$
2. 边值问题
    - 衔接条件1：A
        - $$A_{1n} = A_{2n}$$
        - $$A_{1t} = A_{2t}$$
        - A 在分界面上连续
    - 衔接条件2：
        - $$H_{2t} - H_{1t} = k$$
        - $$\frac{(\nabla\times A_1)_t}{\mu_1} - \frac{(\nabla\times A_2)_t}{\mu_2} = k$$
    - 求解
        - $$\nabla^2 A = -\mu J$$
        - 边界条件
        - 两个衔接条件
---
### 标量磁位
1. 磁位
    - 无电流区（$$\nabla\times H = 0$$）：$$H = -\nabla\varphi_m$$
        - $$B = \mu H$$
            - $$\nabla^2\varphi_m = 0$$（拉普拉斯方程）
---
### 镜像法
- 与静电场的镜像法一模一样
---
### 电感
1. 电感
    - $$自感：L = \frac{\Psi}{I} = \frac{N\cdot\Phi}{I}$$
        - $$单匝线圈：L = \frac{\Phi}{I} = \frac{B\cdot S}{I}$$
        - $$多匝线圈：L = \frac{N\cdot B\cdot S}{I}$$
2. 磁链
    - $$\Psi = N\Phi$$（磁链 = N × 磁通）
3. 电感计算
    - $$设 I -> \oint H\cdot dl = I -> H -> B = \mu H -> \Phi = B\cdot S -> \Psi = N\Phi -> L = \frac{\Psi}{I}$$
4. 互感
    - $$M_{12} = M_{21}$$
    - 计算方法与求自感一样
---
### 磁场能量与力
1. 磁场能量
    - 单线圈：$$W = \frac{1}{2}L\cdot I^2$$
    - 多线圈：$$W = \frac{1}{2}L_1I_1^2 + \frac{1}{2}L_2I_2^2 + M\cdot I_1\cdot I_2$$
        - $$\frac{1}{2}L\cdot I^2$$ -> 自有能
        - $$M\cdot I_1\cdot I_2$$ -> 互有能
2. 能量密度
    - $$w = \frac{1}{2}B\cdot H$$
3. 磁场力
    - 和静电场的一样，用虚位移法求解就行
